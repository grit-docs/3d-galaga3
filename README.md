# HALCYON BREAK (할리온 브레이크)

3D 아케이드 로그라이트 우주 슈터. 3분짜리 한 판이 아니라, **10~20분짜리 9웨이브 런**을 뛰며 매 회차 무기와 능력이 조합됩니다.

## 핵심 시스템 — Resonance Weave (레조넌스 위브)

적은 파괴될 때 **주파수 샤드**(PULSE / ARC / VOID)를 떨어뜨립니다. 같은 주파수 3개를 모으면 **Q** 키로 6초간 해당 주파수의 위브 상태로 전환됩니다(무기 강화 + 특수 효과). 웨이브 클리어마다 3택 1의 영구 업그레이드도 선택해, 매 런마다 다른 빌드가 완성됩니다.

## 설치

```bash
npm install
```

Node.js 18 이상 필요.

## 개발 서버 실행

```bash
npm run dev
```

브라우저에서 Vite가 띄우는 주소(기본 `http://localhost:5173`)로 접속.

## 조작

| 키 | 동작 |
| --- | --- |
| W A S D / 방향키 | 기동 (xy 평면) |
| 마우스 | 3D 조준 |
| 마우스 좌클릭 | 사격 |
| Space | 페이즈 시프트 (시간 둔화 + 대시, 4초 쿨) |
| Q | 위브 발동 (주파수 3/3 필요) |
| R | 노바 폭탄 (적 탄막 소거 + 범위 피해) |
| 1 / 2 / 3 | 무기 슬롯 전환 |
| P / Esc | 일시정지 |

## 빌드

```bash
npm run build        # 타입 체크 + 프로덕션 빌드 (dist/)
npm run preview      # 프로덕션 빌드 실행 확인 (http://localhost:4173)
```

## 테스트 / 린트

```bash
npm test             # Vitest 단위 테스트 (게임 로직)
npm run lint         # ESLint
npm run e2e:install  # Playwright 크로미움 설치 (최초 1회)
npm run e2e          # E2E 스모크 테스트 (프로덕션 빌드 대상)
```

## 구성

```
src/
  game/        순수 TS 시뮬레이션 (엔진, 데이터, 타입) — 렌더링 의존성 없음
  render/      Three.js 렌더러, 파티클, 배경, 절차적 모델
  audio/       WebAudio 절차적 SFX + 앰비언트 (샘플 없음)
  ui/          DOM HUD / 스크린
  App.ts       입력·루프·상태 연결
tests/
  unit/        엔진/무기/웨이브/업그레이드/스코어 단위 테스트
  e2e/         Playwright 스모크 (시작→플레이→HUD→일시정지→게임오버→재시작)
docs/
  game-design.md  게임 디자인 문서
```

- 로직(고정 60Hz 스텝)과 렌더링이 완전히 분리되어 프레임 레이트와 무관하게 결정적으로 동작합니다.
- 모든 자원은 프리미티브 / 셰이더 / 절차 생성으로 생성되며 외부 에셋이 없습니다.
- 설정(볼륨·그래픽 품질)과 최고 기록은 localStorage에 저장됩니다.
