# HALCYON BREAK (할리온 브레이크) — 게임 기획서

## 1. 게임 제목
**HALCYON BREAK**(할리온 브레이크)

## 2. 한 문장 콘셉트
> "붕괴해가는 성단(星團)의 관문(게이트) 네트워크를 돌파하면서, 적의 잔해에서 수확한 **공진(共振) 조각**을 조립해 매번 다른 무기 시너지를 만들어 내는 3D 로그라이트 아케이드 슈터."

## 3. 세계관
- **할리온 성단**은 거대 관문 네트워크로 서로 연결된 별들의 집합체였다. 11년 전 "고요(Stillness)"라는 정체불명의 공진 파동 하나가 관문 핵심을 썩였고, 성단은 지금 이 순간에도 천천히 붕괴하고 있다.
- 플레이어는 **루미나 파일럿**이다. 루미나 파일럿은 "공진 조종석(Resonant Cockpit)"을 몸에 단 파일럿으로, 적과 파편이 방출하는 공진 주파수를 흡수·재조립해 무기를 변형시킬 수 있는 유일한 존재다.
- 적 **홀로(Hollow)**들은 고요의 파동에 오염되어 껍데기만 남은 관문 유지용 기계체들이다. 이들에게 감정이나 목적은 없으며, "관문을 지키는(막는)" 본능만이 남은 상태다.
- 목표: 붕괴를 견디며 관문 네트워크의 최심부 **"널 게이트(Null Gate)"**까지 9개 관문 웨이브를 돌파하고, 성단의 생존 데이터를 실어 나를 마지막 창문을 열어야 한다.

## 4. 핵심 재미
1. **조립의 재미**: 주파수 조각 수집 → 위브 발동 → 무기 변형. "어떤 주파수를 노리며 싸울지"가 매 전투의 전략이 된다.
2. **선택의 재미**: 웨이브마다 3개의 강화 중 1개를 고르는 로그라이트 성장. 무기를 언제 어떤 순서로 해금하느냐에 따라 빌드가 갈린다.
3. **생존의 재미**: 3D 공간에서 접근하는 6종 홀로와 3종 게이트 워든 보스 사이를 위브/페이즈 시프트로 살아남는 긴장감.
4. **점수의 재미**: 콤보 배율(최대 8x)과 파편 수집, 웨이브 클리어 보너스로 최고 기록 경쟁.

## 5. 독창적인 핵심 시스템 — 레조넌스 위브 (Resonance Weave)
기존 "무작위 강화 3택 1"만 있는 로그라이트 슈터와 달리, **전투 중에 스스로 수집한 리소스로 무기를 임시 변형**시키는 이중 성장 축을 가졌다.

- 모든 무기와 적에는 주파수(PULSE / ARC / VOID)가 있다.
- 주파수 f의 적을 처치하면 **f 조각(Shard)**을 떨어뜨린다. 자석 반경 안에 들어오면 플레이어 쪽으로 빨려 온다.
- 3개를 모으면 해당 주파수의 **위브 미터가 가득** 차고, `Q`로 발동하면 현재 장비된 해당 주파수 무기가 **변형 상태(위브 스테이트)**로 6초(강화로 확장 가능) 유지된다.
  - PULSE 위브: 3연사 + 관통 1
  - ARC 위브: 체인거리·목표 증가
  - VOID 위브: 관통 탄이 관통 지점에서 폭발(범위 피해)
  - BLOOM 위브: 스프레드와 탄수 증가
- 전략 포인트: "VOID 위브를 쓰고 싶으면 VOID 적을 일부러 남기고 회피하며 사냥한다"는 식의 **사냥 대상 선택**이 전투 안에 생긴다. 강화 3택 1(영구) + 위브(임시, 수집 기반)의 조합 공간이 매 플레이마다 달라진다.

보조 시스템:
- **페이즈 시프트(Space)**: 0.45초간 시간 지연(적·적탄 35% 속도) + 무적 대시. 냉각 4초.
- **노바 서지(R, 강화 획득 시)**: 적탄 전소거 + 적 전체에 대미지를 주는 원차의 폭탄. 런당 1회.
- **콤보 배율**: 3초(강화로 확장) 안에 처치할수록 배율이 1.0x → 8.0x까지 상승.

## 6. 플레이어 조작 방식
| 입력 | 기능 |
|---|---|
| WASD / 방향키 | 3D 공간 이동 (수평·수직 평면, 전방 -Z) |
| 마우스 | 타워(총) 조준 (3D, 전방 평면 레이캐스트) |
| 마우스 왼쪽(장착 유지) | 발사 |
| Space | 페이즈 시프트 (시간 지연 + 대시) |
| Q | 레조넌스 위브 발동 (현재 무기 주파수 미터 가득 차 있을 때) |
| R | 노바 서지 (강화 보유 시) |
| 1 / 2 / 3 | 무기 슬롯 전환 |
| P / Esc | 일시정지 |

- 시점: 플레이어 뒤上方을 바라보는 3/4 후방 카메라. 이동·대시 시 FOV 킥으로 속도감 표현.
- 이동은 평면 4방이지만 조준은 3D라서, "위치(생존) vs 조준(타격)"의 분리된 손-눈 작업이 아케이드 감각을 만든다.

## 7. 전투 진행 방식
- **웨이브제**: 9개 웨이브. 웨이브 시작 → 데이터 기반 스폰 큐(형성: 스트림/라인/V/플랭크/링)로 적 출현 → 전멸 시 클리어.
- **웨이브 클리어** → 3개 강화 카드 중 1 선택 → 다음 웨이브. (선택 화면에서 시간 정지)
- 3·6·9 웨이브는 **보스 웨이브** (게이트 워든 변형 3종). 보스 등장 1.5초 전 "관문 경보" 연출.
- 9웨이브(널 게이트) 처치 시 **승리 엔딩**, 실패 시 게임 오버.
- 한 판 10~20분: 일반 웨이브 ~40~70초, 보스 웨이브 ~90~150초로 밸런스.

## 8. 성장과 강화 방식
1. **영구 강화(3택 1)** — 데이터 기반 풀 17종, 희귀도(공통/희귀/에픽) 가중치 드롭:
   - 공격: 대미지 +25%, 발사율 +15%, 탄수 +1, 관통 +1, 치명타 15%(2회)
   - 방어: 최대 체력 +25 & 회복, 최대 시ールド +25 & 회복, 시ールド 자연회복(1회), 응급 수리
   - 유틸: 이동속도 +15%, 파편 자석 +75%, 콤보 창 +1초, 위브 지속 +3초
   - 해금(에픽): ARC WEAVE / VOID LANCE / BLOOM SCATTER (슬롯 최대 3)
   - 보너스: 노바 서지 폭탄(1회)
2. **임시 변형(위브 스테이트)**: 5번의 레조넌스 위브 참조. 조각 수집 → Q 발동 → 6초 변형.
3. **웨이브 스케일링**: 웨이브가 오를수록 적 HP·탄 피해가 서서히 증가해 후반 긴장감을 유지.

## 9. 적과 보스 설계
### 홀로 6종 (주파수별)
| 종류 | 주파수 | 행동 | 특징 |
|---|---|---|---|
| 마이트 (Mite) | PULSE | 플레이어 위치로 정현 파동 돌진 | 개체 소형, swarm. 근접 피해 |
| 헐크 (Husk) | PULSE | 초고속 자폭 돌격 | 폭발 반경, 회피 연습 대상 |
| 랜스 (Lance) | ARC | 측면 스트래이핑 + 정조준 직선탄 | 중거리 압박 |
| 위버 (Weaver) | VOID | 플레이어 뒤쪽 원 궤도 + 3방향 스프레드 탄 | 회피 패턴 학습 |
| 래스 (Wraith) | VOID | 페이드-전이-페이드 + 유도 탄(회전률 제한) | 2장 드롭, 고위협 |
| 볼웩 (Bulwark) | PULSE | 느린 정면 전진 + 파편 2개 | **PULSE 탄만 전체 피해, 다른 주파수는 25%** 방패. 주파수 대응 사격 학습 |

### 보스 3종 (게이트 워든 변형)
| 보스 | 등장 | HP | 패턴(단계별) |
|---|---|---|---|
| 워든 프라임 | 3웨이브 | 700 | ① 나선 탄막(3암) → ② 정조준 3연 → ③ 방사 탄막 16발 + 마이트 소환 |
| 워든 헥스 | 6웨이브 | 1300 | ① 방사 14 → ② 나선 4암 + 위버 소환 → ③ 정조준 5방향 |
| 널 게이트 | 9웨이브(최종) | 2400 | ① 나선 5암 → ② 방사 22 + 헐크 소환 → ③ 정조준 4연 → ④ 나선 6암 + 래스 소환 |

- 보스는 Z축 -26 부근에서 사인 함수 궤적으로 호버하며, HP 임계점(0.66/0.33/…)에서 패턴 전환 + 경보 연출.
- 보스 처치 시 파편 4~6개 + 고배점.

## 10. 스테이지 진행 방식
- 단일 3D 아레나(관문 통로): X ±16 / Y ±7 / 플레이어 Z -10~6. 적 출현 지대는 Z -50 부근.
- 배경: 절차적 성운 셰이더 + 2층 별자리(패럴랙스) + 관문 링(통로를 지나는 토러스 고리) + 흐르는 그리드 → 속도감과 깊이를 부여.
- 웨이브 진행에 따라 배경 색조가 천천히 변함(초기 청록 → 후반 자홍)으로 "깊이 들어가고 있다"는 감각.

## 11. 점수와 재도전 구조
- **점수**: 처치 기본점(50~200) × 콤보 배율(최대 8x) + 웨이브 클리어 보너스(500×웨이브) + 최종 승리 보너스 5,000.
- **최고 기록**: localStorage에 저장, 타이틀·HUD·게임오버에 표시. 신규 기록 시 "NEW BEST" 표시.
- **재도전**: 게임오버/승리 화면에서 즉시 재시작(신규 시드 → 매번 다른 강화 드롭·적 배치) 또는 타이틀 복귀.
- **통계**: 게임오버 화면에 도달 웨이브, 처치 수, 플레이 시간 표시.

## 12. 비주얼과 사운드 방향
### 비주얼
- **현대적 SF**: 어두운 우주 배경 위에 주파수별 네온 발광(청록/보라/분홍). 기본 도형(정육배면체·다odecahedron·토러스 등) + 발광 재질 + 추가 혼합(additive) 글로우 스프라이트로 "착한 블룸" 구현.
- **효과**: 폭발 파티클(풀 기반 Points), 적중 스파크, 체인 라이트닝 라인, 피격 화면 흔들림, 페이즈 시 FOV 킥+이중曝光.
- **HUD**: 유리질(glass) 패널 + 네온 테두리, 체력/시ールド 바, 무기 슬롯(위브 파이프 3개), 콤보 배율, 웨이브 표시, 보스 HP 바.
- **품질 단계**(저/중/고): 픽셀비율, 파티클 용량, 별 수, 성운 셰이더 유무, 안티앨리어싱, 톤매핑을 단계별로 조절 → 저사양 대응.
- 모든 자원은 절차적 생성(기본 도형, 셰이더, 캔버스 글로우 텍스처). 외부 자산 0.

### 사운드 (WebAudio 절차적 합성, 외부 샘플 0)
- **효과음**: 주파수별 발사 톤(주파수마다 다른 기본 주파수), 적중 노이즈, 폭발(로우패스 스위프+신트 드롭), 파편 줍기 아코디크, 피격, 페이즈 휘쉬, 위브 실버, UI 블립.
- **배경음악**: 생성형 앰비언트 루프 — 드론(디튠트 저음)+A 소르 pentatonic 아르페지오+소프트 킥. 루트 진행은 런 시드에서 결정되어 매 플레이가 약간씩 다름.
- **설정**: SFX 볼륨, 음악 볼륨, 음악 ON/OFF, 그래픽 품질(저/중/고) — localStorage 영구 저장.

## 13. 기술 구조 (개발 원칙)
- **로직/렌더링 분리**: `src/game`은 순수 TypeScript 시뮬레이션(Three.js 미사용, 결정적), `src/render`은 Three.js 렌더러, `src/audio`는 WebAudio, `src/ui`는 DOM HUD/스크린.
- **고정 시간간격**: 로직은 60Hz 고정 스텝 + 어큐뮬레이터로 진행 → 프레임레이트와 무관하게 동일 시뮬레이션 (동일 시드+동일 입력 = 동일 결과, 테스트로 검증).
- **데이터 기반**: 무기·적·보스·웨이브·강화 모두 `src/game/data`의 데이터 객체로 정의 → 밸런스 수정은 코드 구조 변경 없이 가능.
- **리소스 정리**: 객체 풀, 화면 밖 객체 제거, 이벤트 리스너/RAF/Three 리소스 dispose 관리.
- **검증**: Vitest(로직 단위 테스트) + ESLint + Playwright(프로덕션 빌드 대상 브라우저 스모크: 시작→플레이→HUD→일시정지→강화→게임오버→재시작, 콘솔 오류 0).
